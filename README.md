# Practice Drawing Characters

This project is a lightweight browser-based Chinese character flashcard practice tool.

## Features

- Draw and practice stroke order on a responsive canvas
- Load flashcard sets from JSON files
- Add flashcards with optional image media
- Local storage saves and loads user-created decks
- Keyboard shortcuts: `n` = next card, `t` = toggle character, `c` = clear canvas

## How to use

1. Open `index.html` in a web browser.
2. Upload flashcards via the browse panel or use built-in HSK deck.
3. Add new cards using the form.
4. Use buttons or keyboard shortcuts for quick practice.

## Notes

- Flashcards are persisted in `localStorage` under `flashcards` key.
- Download and upload flashcard set as JSON from the main UI.
